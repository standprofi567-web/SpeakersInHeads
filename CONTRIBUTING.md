# Contributing / Участие в проекте

For a bug, include the affected game and mod versions, reproduction steps, and relevant sanitized logs. For sound issues, say whether the setup uses a single head, a pair, or a group, and whether SPR is installed. Use [Security](SECURITY.md) for private vulnerability reports.

Use Java 25 and run the Gradle wrapper. Keep changes focused and preserve the behavior of existing worlds and configurations. See [Development](docs/en/DEVELOPMENT.md) for build and test commands.

Если нашёл ошибку, укажи версии игры и мода, шаги воспроизведения и приложи фрагмент лога без личных данных. При проблеме со звуком укажи, использовалась ли одна голова, стереопара или группа и установлен ли SPR. Об уязвимостях сообщай через [Security](SECURITY.md).

Используй Java 25 и Gradle Wrapper. Сохраняй совместимость с существующими мирами и настройками. Команды сборки и тестов есть в [руководстве разработчика](docs/ru/DEVELOPMENT.md).
