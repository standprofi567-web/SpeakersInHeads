# Security policy

Report a reproducible security problem privately through GitHub **Security → Report a vulnerability** when enabled. If private reporting is unavailable, request a private contact channel in Issues and leave the technical details out of the public issue.

Include the mod version, Minecraft and Fabric versions, expected result, and a minimal reproduction. Sanitize logs and omit credentials, account files, private server details, and private media URLs. The current public beta is the supported release line.
