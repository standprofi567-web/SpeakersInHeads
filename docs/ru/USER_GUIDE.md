# Руководство пользователя

## Музыкальная библиотека

Открой **Music Mixer → Manage Library → Open Music Folder**. Положи MP3, Ogg Vorbis или поддерживаемые PCM WAV в `music/speakersinheads` внутри активной папки игры. Дождись завершения копирования. Если треки ещё не появились, нажми **Refresh Library**. Кнопка **Import File** позволяет выбрать файл из другой папки. **Copy Path** доступна, если не получается открыть Проводник.

## Воспроизведение и колонки

- Выбери трек и нажми **Play**. **Pause** и **Resume** сохраняют позицию. Перематывай трек на шкале времени, а порядок задавай через Repeat и Shuffle.
- Открой управление группой в микшере. Добавь нужные головы и выставь **Group Volume**. Кнопка **Sync Now** запрашивает коррекцию во время воспроизведения.
- В настройке стереопары выбери отдельные места для левого и правого каналов стереозаписи. Громкость пары регулируется через **Pair Volume** в микшере.
- В **Settings → Spatial Audio** отдельно задай максимальную дальность и расстояние полной громкости. Приглушение стен и подводный фильтр настраиваются в **Acoustics**. SPR можно установить отдельно для его эффектов окружения.
- Громкость категории Minecraft, громкость SIH и усиление выхода регулируются отдельно. При слышимых искажениях убавь Output Boost. Темы и анимации доступны в **Appearance**.

## Smart Music Import

Вставь поддерживаемую страницу трека или ссылку на аудиофайл и нажми **Inspect**. **Metadata Found** относится к информации о треке, **Audio Available** показывает доступность файла. Используй **Find Local**, чтобы найти запись в библиотеке, или **Import Local File**, чтобы выбрать свою копию. Кнопка **Download & Import** появляется для разрешённого прямого файла или доступной загрузки с Jamendo. После импорта библиотека обновляется.

Spotify может отдавать название и обложку через oEmbed. Имя исполнителя доступно не всегда. Для обращения к официальному Spotify Web API используется отдельно настроенный `SIH_SPOTIFY_ACCESS_TOKEN`. Метаданные Spotify не дают доступ к аудио.
