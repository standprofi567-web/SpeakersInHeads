# Диагностика

| Симптом | Что проверить |
| --- | --- |
| Меню не открывается | Нажми Shift + ПКМ по голове игрока на полу или стене. Проверь список загруженных модов в клиентском журнале. |
| Нет звука | Проверь громкость SIH, группы или пары, выбранной категории Minecraft и расстояние. Сравни с одной головой на том же треке. |
| Нет трека в списке | Проверь путь через Open Music Folder или Copy Path. Дождись завершения копирования и нажми Refresh Library. Ogg Opus не поддерживается. |
| Папка музыки не открылась | Используй Copy Path и вставь путь в Проводнике. Подробности ищи в свежем логе по времени попытки открытия. |
| У Spotify нет загрузки | Используй Find Local или Import Local File. Со страницы Spotify можно получить доступные метаданные. |
| Слышен рассинхрон группы | Запиши время, количество колонок, расстояние и действия перед проблемой. Укажи, были ли выгрузка чанка, пауза или Sync Now. Сравни в тех же настройках громкости и пространственного режима. |

Логи находятся в папке `logs` активного профиля. При сбое проверь также `crash-reports` и `hs_err_pid*.log`. Перед отправкой убери из логов личные пути, аккаунты, адреса серверов и данные авторизации.
